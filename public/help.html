Organize your first folder

  1. In Finder, create two temporary folders named Tidy Sample and Tidy Output. Put a few copied files in Tidy Sample.
  2. In Tidy, click Browse… under Source and choose Tidy Sample. Under Destination, choose Tidy Output. You can also drag a folder onto either card.
  3. Under Automated rules, enable the categories that match the file types you want to organize.
  4. Click Run Tidy to see the proposed moves. Check the files and destination folders, then click Confirm & Run if everything looks right.
Run Tidy opens a preview. Confirm & Run moves the files.

Choose which files Tidy includes

Tidy starts with files directly inside the source folder. Turn on Include subfolders to scan nested folders and choose which folders to include. Tidy leaves the original folders in place. Choose a destination different from the source when scanning subfolders.

Use the file-type choices to narrow the scan and Smart filters to limit files by date modified or size. Turn on Exclude hidden to skip names that begin with a dot. Files must match the selected scope, filters, and an enabled category.

Choose Older than… under Date modified to enter a cutoff in whole days. To find a file later, use Find organized files in the toolbar and describe it. Tidy searches filenames and text that Spotlight has indexed in the organized folder.

The Books rule includes EPUB, MOBI, Kindle formats such as AZW3, comic archives such as CBZ and CBR, and M4B audiobooks. PDF remains in Documents.

If you clear a folder or file-type selection, select the items you want before previewing again. An empty selection does not mean “include everything.”

Review changes and undo a run

The preview shows which files match and where Tidy proposes moving them. Review suggested names and folders, especially when multiple files have the same name. If you need to change the source, filters, or rules, close the preview and run it again.

Focus a file row and press Space, or click its Quick Look button. Select Apply Finder tags in place to add category tags. In move mode, you can group files by download website or photos by capture year and month. Files without the selected metadata follow their category rules.

After a run, use Undo Changes to put files back. You can also choose Edit → Undo Last Organize when an undo is available. If a new file already occupies an original location, Tidy leaves it in place and reports the conflict.

With Move duplicates to Trash and duplicate detection enabled, identical copies go to the Trash. Use Put Back in Finder to restore them.

Schedule runs

In Schedule and conflicts, choose Daily, Weekly, or Monthly and set a time. Weekly runs occur on Monday and monthly runs on the first day. Choose Manual to turn the schedule off.

Turn on Watch for new files to organize new arrivals while Tidy is running. Watching starts with a baseline of existing files and waits for new files to settle. The Tidy menu bar icon can reopen the window, enable Launch at Login in the installed app, or quit Tidy.

The installed macOS app can run your schedule while Tidy is closed and you are logged in. Allow background activity and notifications in System Settings. Use Undo in a scheduled-run notification or choose Edit → Undo Last Organize in Tidy. Tidy can stay in the menu bar after delivering a scheduled notification.

Use Gemini features

  1. Open Settings from the Tidy menu or press ⌘,.
  2. Under Gemini API key, enter your key and click Save key.
  3. Click Test connection to confirm Gemini accepts the key.
Suggest rules for this folder
Shares a sample of filenames with Gemini and opens a review of the proposed categories. Applying the proposal updates your active rules.
AI rules
Describe what you want to organize in plain language. Tidy proposes settings for you to review. It may ask a follow-up question when a detail is missing.
Smart Rename
Suggests clearer filenames for generic names and keeps descriptive names as written. Choose a descriptive or date-first naming style and review suggestions in the preview. Accepted offline renames stay in their assigned category.
Smart Sort
Suggests more specific destination subfolders based on what the files contain. Smart Sort folders by year adds a year from a recognized document date, photo capture date, or the file’s modified date.

Gemini features use Google’s online service. Smart Rename and Smart Sort may send supported file contents. The connection test sends a short test message. Basic rules, previews, moves, and undo work without Gemini.

Choose On-device text recognition under Analyze files with to suggest names and folders from text in supported images and first pages of PDFs. Files and recognized text stay on this Mac in that mode.

Troubleshoot

The preview is empty

Check that the source contains matching files, the relevant category is enabled, and the file type is selected. For nested files, turn on Include subfolders and select their folders. Try relaxing the date or size filter.

Tidy can’t read or write to a folder

Check that the folder still exists and that its drive is connected. Choose the folder again with Browse…. If macOS denied access, review Tidy’s permissions under System Settings → Privacy & Security → Files and Folders.

Gemini won’t connect

Open Settings and click Test connection. If authorization fails, check that the key is valid and has Gemini API access. If you hit a usage limit, check your Google API quota or try again later.

You still need help

Choose Help → Report an Issue. Include your Tidy version, the steps you took, and the error text. Leave out your API key and private file contents.
